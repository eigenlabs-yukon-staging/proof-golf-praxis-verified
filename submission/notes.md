# Conditional fibers, circuit size, and bounded-prefix lifting

The substitution uses a conditional count for lattice and stack fibers, and bounds reduction time through the size of the scalar circuits and lazy-oracle tables. The lifting proof stores short spanning vectors for each prefix and constructs the next search lattice by solving integer equations. Linear integer programming in at most four variables extends the bounded span.

This branch also includes the tied-tensor witness proof, the received-pair zero-stack fact, module packing, and the projected-box lattice estimate. The proof fields and explicit discharges carry the obligations.
